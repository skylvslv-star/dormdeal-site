## Publishing

GitHub Pages serves the `main` branch from `/ (root)`. `.nojekyll` keeps these static files unchanged. Edit HTML/CSS and commit to main to publish. No package installation, build service, or application deployment is needed. Support contact: dormdeal.marketplace@gmail.com.

The privacy policy avoids claims of complete automatic deletion, fixed retention periods, future AI processing, or no data collection. Support and privacy therefore provide an email route for complete deletion requests. The operator must handle those requests and review remaining records.
